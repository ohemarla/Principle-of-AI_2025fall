	\section{任务介绍}

	本次作业的目标是构建并训练一个用于图像分类任务的深度学习模型，所用数据集包含5类花卉图像，分别为daisy、dandelion、rose、sunflower和tulip，数据集已经分好成训练集和验证集以及测试集。具体任务包括模型设计与实现、训练过程分析以及结果展示。
	\section{模型架构}
	为了实现图象分类，我根据ResNet架构搭建了一个卷积神经网络模型。该模型共包含4个主要残差层，各层的残差块的数量分别为 3、4、6 和 3 个，每个残差块采用的是ResNet34架构中的基础块，它由两个$3\times3$卷积层和一个残差连接构成。以下部分将分别介绍残差块的结构、整体网络架构、数据预处理与增强方法，以及模型的超参数设置与训练配置。
	\subsection{Residual Block}
	残差块是ResNet架构的核心组件，旨在解决深层网络中的梯度消失问题。每个残差块由两个连续的$3\times 3$卷积层构成：第一层卷积的步长由\lstinline|stride|控制，在进行下采样时步长为2，否则为1；第二层卷积固定使用步长为1。步长为1的时候能保持分辨率不变是因为两个卷积层均使用\lstinline|padding=1|，同理步长为2的时候分辨率会变成输入的一半。通道数由\lstinline|in_channels|和\lstinline|out_channels|指定。每个卷积层后面都跟有批归一化层和ReLU激活函数，并且在第二个批归一化层后、激活函数前进行残差连接。为了保证残差连接时参与相加的两路特征在维度上的一致性，当输入和输出的通道数不匹配或步长不为1时，会通过一个$1\times 1$卷积层和批归一化层对输入进行调整。在本模型中，\lstinline|expansion|被设置为1，输出通道数不进行额外扩张，如果需要扩张可以调整该参数，例如在ResNet50中，\lstinline|expansion|就需要设置为4。下面是残差块的具体实现代码：
	\begin{lstlisting}
class ResidualBlock(nn.Module):
    expansion = 1	# ResNet34
    def __init__(self, in_channels, out_channels, stride = 1):
        super(ResidualBlock, self).__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 
                               kernel_size=3, stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 
                               kernel_size=3, stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)
        self.shortcut = nn.Sequential()	# 残差连接
        if stride != 1 or in_channels != self.expansion * out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, self.expansion * out_channels, 
                          kernel_size = 1, stride = stride, bias = False),
                nn.BatchNorm2d(self.expansion * out_channels)
            )
            
    def forward(self, x):
        out = self.conv1(x)
        out = self.bn1(out)
        out = self.relu(out)
        out = self.conv2(out)
        out = self.bn2(out)
        out += self.shortcut(x) # F(x) + x
        out = self.relu(out)
        return out
	\end{lstlisting}
	\subsection{整体网络架构}
	基于上述残差块，这里构建了一个包含4个主要残差层的深度卷积神经网络。
	
	网络的第一部分是一个初始的卷积层，使用\lstinline|stride|为2和\lstinline|padding|为3的$7\times 7$卷积核进行卷积操作，将输入图像的分辨率从$224\times 224$降至$112\times 112$，随后接一个批归一化层和ReLU激活函数。这之后通过一个\lstinline|stride|为2和\lstinline|padding|为1的$3\times 3$Max池化层进一步将分辨率降至$56\times 56$。

	接下来是4个残差层，分别包含3、4、6和3个残差块。经过第一个残差层，图的分辨率保持为$56\times 56$；经过第二个残差层时，图的分辨率降至$28\times 28$；经过第三个残差层时，分辨率进一步降至$14\times 14$；最后经过第四个残差层时，分辨率降至$7\times 7$。每个残差层的输出通道数依次为64、128、256和512，所以最终输出的张量维度为$512\times 7\times 7$。
	
	在经过4个残差层之后，网络通过平均池化层进一步将张量维度降低到$512\times 1\times 1$，并随后展平为512维的向量，最后通过一个全连接层的分类头映射到5个类别上，完成分类任务。

	为了更完整的实践神经网络的搭建与训练过程，这里不使用预训练权重，而是初始化网络中的权重参数，如果是卷积层则使用Kaiming初始化，批归一化层的权重初始化为1，偏置初始化为0。下面是整体网络架构的具体实现代码：
	\begin{lstlisting}
class ResNet(nn.Module):
    def __init__(self, block, layers, num_classes):
        super(ResNet, self).__init__()
        self.in_channels = 64
        self.conv1 = nn.Conv2d(3, 64, kernel_size = 7, stride = 2, padding = 3, bias = False) # 7x7的初始卷积层，224 -> 112
        self.bn1 = nn.BatchNorm2d(64)
        self.relu = nn.ReLU(inplace=True)
        self.maxpool = nn.MaxPool2d(kernel_size = 3, stride = 2, padding = 1) # Max池化层，112 -> 56
        self.Layer1 = self._make_layer(block, 64, layers[0], stride = 1) # 第一层，56 -> 56
        self.Layer2 = self._make_layer(block, 128, layers[1], stride = 2) # 第二层，56 -> 28
        self.Layer3 = self._make_layer(block, 256, layers[2], stride = 2) # 第三层，28 -> 14
        self.Layer4 = self._make_layer(block, 512, layers[3], stride = 2) # 第四层，14 -> 7
        self.avgpool = nn.AdaptiveAvgPool2d((1, 1)) # 平均池化层，7 -> 1
        self.fc = nn.Linear(512 * block.expansion, num_classes) # 全连接层
        self._initialize_weights()
    
    def _make_layer(self, block, out_channels, blocks, stride = 1):
        layers = []
        layers.append(block(self.in_channels, out_channels, stride))
        self.in_channels = out_channels * block.expansion   # 更新输入通道数
        for _ in range(1, blocks):  # 添加剩余的残差块
            layers.append(block(self.in_channels, out_channels))
        return nn.Sequential(*layers)
    
    def _initialize_weights(self):
        for m in self.modules():
            if isinstance(m, nn.Conv2d):
                nn.init.kaiming_normal_(m.weight, mode='fan_out', nonlinearity='relu')
            elif isinstance(m, nn.BatchNorm2d):
                nn.init.constant_(m.weight, 1)
                nn.init.constant_(m.bias, 0)
        
    def forward(self, x):
        x = self.conv1(x)
        x = self.bn1(x)
        x = self.relu(x)
        x = self.maxpool(x)
        x = self.Layer1(x)
        x = self.Layer2(x)
        x = self.Layer3(x)
        x = self.Layer4(x)
        x = self.avgpool(x)
        x = torch.flatten(x, 1)
        x = self.fc(x)
        return x
	\end{lstlisting}
	\subsection{数据预处理与增强}
	在数据预处理方面，考虑到提供的花卉图象具有不同的分辨率，所以这里我设计了一个\lstinline|Sample|函数来读取对应数据，构造好样本，并把子文件夹名当作图片的标签。对于训练集，首先对读取到的图象进行统一的缩放，将较短边调整为256像素，然后随机裁剪出$224\times 224$的区域，随后进行了一系列经典的数据增强操作，包括随机水平翻转、随机旋转（角度范围为$\pm 15$度）、颜色抖动（亮度、对比度、饱和度和色调的调整范围分别为0.2、0.2、0.2和0.1）。完成前面的增强步骤后将图象转换为张量并进行归一化处理，进行归一化的均值和标准差均采用ImageNet数据集的统计值是因为我认为这个值会比直接用0.5和1.0更合适一些，能更好地适应自然图象的分布。最后一步加入了随机擦除操作，擦除的概率为0.1，擦除区域的比例范围为0.02到0.33，更进一步的提升模型的泛化能力。对于验证集和测试集，则采用统一的缩放和中心裁剪来保证输入图象的一致性，除了不进行数据增强和随机擦除外，其他处理步骤与训练集相同。下面是数据预处理与增强的具体实现代码：
	\begin{lstlisting}
def Sample(data_path, reinforce = False, batch_size = 32):
    IMAGENET_MEAN = (0.485, 0.456, 0.406)   # ImageNet数据集的均值
    IMAGENET_STD = (0.229, 0.224, 0.225)    # ImageNet数据集的标准差
    if reinforce:   # 如果reinforce为True，则进行数据增强
        transform = transforms.Compose([
            transforms.Resize(256),
            transforms.RandomResizedCrop(224), # 随机裁剪224x224
            transforms.RandomHorizontalFlip(),  # 随机水平翻转
            transforms.RandomRotation(15),  # 随机旋转
            transforms.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2, hue=0.1), # 随机颜色抖动
            transforms.ToTensor(),
            transforms.Normalize(IMAGENET_MEAN, IMAGENET_STD), # 归一化
            transforms.RandomErasing(p=0.1, scale=(0.02, 0.33)) # 随机擦除
        ])
    else:
        transform = transforms.Compose([
            transforms.Resize(256),
            transforms.CenterCrop(224),
            transforms.ToTensor(),
            transforms.Normalize(IMAGENET_MEAN, IMAGENET_STD)
        ])
    dataset = datasets.ImageFolder(root = data_path, transform = transform)
    dataloader = torch.utils.data.DataLoader(dataset, batch_size = batch_size, shuffle = True)
    return dataloader
	\end{lstlisting}
	\subsection{模型超参数与训练设置}
	在模型的训练过程中，选择了多分类任务中常用的交叉熵作为损失函数。训练批次大小设置为64，最大训练轮次设置为100个epoch。初始学习率设置为0.001，而在训练中使用\lstinline|CosineAnnealingLR|余弦退火调节器来调整学习率，周期设置为最大训练轮次。优化器这里选择了AdamW优化器，权重衰减系数为0.001，以帮助模型更好地收敛并防止过拟合。为了进一步防止过拟合，我设定了一个早停机制，耐心值为15，即如果在连续15个epoch内验证集的准确率没有提升，则提前终止训练过程，而训练过程中会保存下验证集上准确率最高的模型的权重。为了更好的监控训练过程，我使用了TensorBoard来记录训练和验证的损失及准确率。下面是训练配置的具体实现代码：
	\begin{lstlisting}
def Train(num_classes, batch_size, lr, epochs, patience,
          train_data_path, val_data_path, save_model_path, log_dir, device):
    writer = SummaryWriter(log_dir)  # TensorBoard日志记录器
    model = ResNet(ResidualBlock, [3, 4, 6, 3], num_classes).to(device)
    optimizer = optim.AdamW(model.parameters(), lr=lr, weight_decay=0.001)
    scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs)
    train_loader = Sample(train_data_path, reinforce=True, batch_size = batch_size)
    val_loader = Sample(val_data_path, batch_size = batch_size)
    best_val_accuracy = 0
    epochs_no_improve = 0
    global_step = 0
    for epoch in range(epochs):
        running_loss = 0.0  # 记录训练集损失
        correct_train = 0  # 记录训练集正确预测数
        total_train = 0    # 记录训练集总数
        for inputs, labels in train_loader:
            inputs, labels = inputs.to(device), labels.to(device)
            optimizer.zero_grad()
            outputs = model(inputs)
            loss = criterion(outputs, labels)
            running_loss += loss.item() * inputs.size(0)
            _, predicted_train = torch.max(outputs.data, 1)
            total_train += labels.size(0)
            correct_train += (predicted_train == labels).sum().item()
            loss.backward()
            optimizer.step()
            global_step += 1
        epoch_loss = running_loss / len(train_loader.dataset)   # 计算epoch的平均损失
        train_accuracy = 100 * correct_train / total_train
        writer.add_scalar('Train/Loss_Epoch', epoch_loss, epoch)
        writer.add_scalar('Train/Accuracy', train_accuracy, epoch)
        val_accuracy, val_loss = Evaluate(model, val_loader, device)    # 在验证集上评估
        writer.add_scalar('Validation/Accuracy', val_accuracy, epoch)
        writer.add_scalar('Validation/Loss', val_loss, epoch)
        print(f"Epoch {epoch+1}, "
              f"Train Loss: {epoch_loss:.4f}, "
              f"Train Accuracy: {train_accuracy:.2f}%, "
              f"Validation Loss: {val_loss:.4f}, "
              f"Validation Accuracy: {val_accuracy:.2f}%")
        scheduler.step()    # 根据验证集准确率更新学习率
        if val_accuracy > best_val_accuracy:
            best_val_accuracy = val_accuracy
            epochs_no_improve = 0
            torch.save(model.state_dict(), save_model_path)  # 保存最佳模型权重
        else:
            epochs_no_improve += 1
            if epochs_no_improve >= patience:
                break
    writer.close()  # 关闭TensorBoard记录器
    model.load_state_dict(torch.load(save_model_path))  # 加载最佳模型权重
    return model

    num_classes = 5
